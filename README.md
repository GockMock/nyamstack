# Nyamstack

Nyamstack — учебный pet-проект: Telegram-бот для учёта питания и КБЖУ.

Цель проекта — помочь пользователю записывать приёмы пищи, учитывать калории, белки, жиры и углеводы, а также получать дневную статистику.

## Идея

Основные сценарии:

- поиск и добавление брендовых продуктов;
- оценка обычных блюд без точных данных;
- ручное добавление пользовательских продуктов;
- сохранение подтверждённых приёмов пищи в дневной рацион;
- просмотр статистики КБЖУ за день.

В проекте разделяются два типа еды:

- `branded` — конкретные продукты с известными КБЖУ;
- `generic` — обычные блюда, КБЖУ которых могут быть оценены приблизительно.

## Стек

- Python 3.13
- aiogram
- SQLAlchemy 2.x
- asyncpg
- PostgreSQL
- Alembic
- pydantic-settings
- Docker / Docker Compose
- pytest планируется для тестирования

## Текущий статус

Проект находится на раннем этапе разработки.

Уже настроены:

- базовая структура Python-проекта;
- PostgreSQL через Docker Compose;
- загрузка настроек из `.env` через `pydantic-settings`;
- асинхронный SQLAlchemy engine;
- фабрика `AsyncSession`;
- async-шаблон Alembic;
- базовый класс SQLAlchemy ORM;
- начата модель `User`.

## Переменные окружения

Пример переменных находится в `.env.example`.

Реальные значения должны храниться в `.env`, который не коммитится в Git.

## Запуск PostgreSQL

```bash
docker compose up -d
```

Проверка контейнера:

```bash
docker compose ps
```

## Проверка подключения к БД

```bash
python -m scripts.check_db
```

Ожидаемый результат:

```text
1 engine ok
1 factory ok
```
